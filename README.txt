DEPLOY FOR FREE WITH NETLIFY DROP
1. Download ALFA_ALFA_Safety_Services_Website.zip.
2. Extract/unzip it on your computer.
3. Open https://app.netlify.com/drop.
4. Sign in or create a Netlify account.
5. Drag the extracted folder named ALFA_ALFA_Safety_Services_Website into the page.
   Make sure index.html, style.css and script.js are directly inside that folder.
6. Wait for the deployment to finish. Netlify will display a public URL ending in netlify.app.
7. Open that URL in a private/incognito window and on a phone to check it is public and responsive.
8. Save the URL and share it with customers.
9. To update the site later, edit the files, zip or extract the updated folder, then deploy the updated folder through Netlify Drop again.
